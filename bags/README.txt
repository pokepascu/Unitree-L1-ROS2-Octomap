Data collected with the robotec based platform with Unitree L1 Lidar on August 7. It was recorded in ROS2 Humble. The base ran on ROS1 noetic (passed to ROS2 using ros1_bridge) and the lidar ran in ROS2 Humble.

rosbag2_2026_08_07-21_13_45 was collected in the Lab.

rosbag2_2026_08_07-21_31_58 and rosbag2_2026_08_07-21_48_31 were collected on Floor 4.

The bag contains Odom,TF and cmd_vel from the base.

Use unitree_l1.rviz to view the lidar data in Rviz2.
