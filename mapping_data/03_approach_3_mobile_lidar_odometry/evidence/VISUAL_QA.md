# Approach 3 RViz visual QA

This is an automated QA of the actual canonical RViz PNG captures. It is a diagnostic and does not replace the screenshots themselves.

Working extrinsic: translation `(0,0,0) m`, roll `0 deg`, pitch `0 deg`, yaw `+23.0 deg`, fixed for the rigid LiDAR mount.

The viewport analysis crops the left RViz display panel and toolbar, estimates the dominant dark background from the viewport corners, detects pixels that differ materially from that background, and separately tracks chromatic pixels likely to contain map/axes/path content. The test is intended to catch blank, clipped, or grossly under-filled captures; it is not a metrological map-quality score.
