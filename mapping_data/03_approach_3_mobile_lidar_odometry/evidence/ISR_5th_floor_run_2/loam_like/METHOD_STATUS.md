# LOAM-like / LiDAR-inertial status

No LOAM-family or LiDAR-inertial map is presented as canonical unless the required IMU-to-LiDAR rotational extrinsic is independently established. The zero robot/LiDAR translation alone does not establish that IMU rotational calibration. KISS-ICP v1.3.0 remains the validated LiDAR-only mobile estimator in this dataset.
