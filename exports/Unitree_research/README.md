# Unitree L1 LiDAR mapping research

These documents assess the Unitree L1's effectiveness for indoor robotic
perception and mapping and define the experiments needed to validate its
performance.

## Performance assessment

- [Revised evidence-based performance assessment](Unitree_L1_Evidence_Based_Performance_Assessment_Revised.pdf)
  — current literature review and secondary analysis of published mapping,
  odometry, and point-cloud performance.
- [Original evidence-based performance assessment](Unitree_L1_Evidence_Based_Performance_Assessment.pdf)
  — retained as the initial version of the assessment.

## Experimental protocols

- [Remaining experiments protocol](Unitree_L1_Remaining_Experiments_Protocol.pdf)
  — controlled range, scan coverage, ROS 2 stream, and trajectory validation.
- [Experimental protocol, English](Unitree_L1_Experimental_Protocol_Short_Paper_EN.pdf)
  — accelerated, reproducible procedure intended to support a short paper.
- [Protocole expérimental, français](Protocole_experimental_Unitree_L1_short_paper.pdf)
  — French version of the accelerated experimental procedure.

## Implementation

- [Codex implementation specification](Unitree_L1_Codex_Implementation_Specification.pdf)
  — ROS 2 Humble and Docker implementation brief for automating the evaluation.
