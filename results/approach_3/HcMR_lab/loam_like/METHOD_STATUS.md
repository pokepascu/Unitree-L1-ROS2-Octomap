# LOAM-like comparison status

No LOAM-like map is labelled as completed in this dataset unless a ROS 2 implementation is validated against the Unitree L1 PointCloud2 schema and timing fields. The repository contains IMU and LiDAR data, but compatibility and the required calibration must be demonstrated before publishing a canonical map. This folder is intentionally explicit rather than presenting an unvalidated result as evidence.

KISS-ICP is executed as the validated generic PointCloud2 LiDAR-odometry comparison. The recorded robot odometry is preserved independently for comparison.
